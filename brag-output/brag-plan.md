# Brag Plan: PrepifyAI

## What is this app?
PrepifyAI is an AI study app for Pakistani FBISE Class 9 students: read the real board textbook, get quizzed on it, and master every topic along a Duolingo-style path — with Prepi the owl as a friendly guide.

## The angle
"Board prep that finally feels like a game." A warm, premium ed-tech film: the real textbook on one side, a friendly owl and a winding mastery path on the other. Not a features list — the actual teach → test → celebrate loop.

## Hook (first 2-3 seconds)
Prepi the owl bobs up on a warm cream field; "PrepifyAI" settles in with "Your FBISE study buddy." Calm, confident, inviting.

## Key moments (the middle)
- The textbook reading panel with real SLO chips — "learn from the real book."
- The winding learning path: nodes light up one by one (mastered ✓ → current pulse → locked).
- The quiz: a correct answer snaps green, score hits 92%, Prepi celebrates.

## Outro / punchline
"Read. Test. Master." with the PrepifyAI wordmark and Prepi waving.

## User flow worth showing
Open a topic → read the real textbook → follow the path → pass the quiz → Prepi celebrates → topic mastered. The centerpiece scenes show this flow, not a marketing list.

## Tone
- Preset: polished
- Creative direction: quiet, premium ed-tech product film with a warm friendly mascot
- Interpretation: fewer scenes, longer holds, soft crossfades; confidence through restraint, warmth through Prepi and the terracotta palette.

## Format: landscape — 1920x1080
## Duration: ~19s

## Visual identity (from the project)
- Background: #f5ead8 (warm cream)
- Card: #fdf7ea
- Accent: #c67139 (terracotta) / deep #8f4a20
- Mastery green: #7a8a5e
- Text: #201e1d
- Display font: Caprasimo (fallback Georgia); Body font: Figtree (fallback system sans)
- Strongest visual element: Prepi the owl + the winding learning path + terracotta palette

## Share copy (draft)
PrepifyAI turns FBISE Class 9 into a game: read the real textbook, beat the quiz, and level up every topic with Prepi. 🦉📚

## Audio direction
- Role: warm, understated bed
- Music: bundled "happy-beats-business-moves-vol-1" — light, positive, not busy
- Music treatment: start at 0, ~0.6 volume, gentle fade-out in the last ~1.2s
- Music cue guidance: preset available; target a soft accent near the celebrate moment (~13s). Cue metadata is guidance only — readability and pacing stay primary.
- Audio-reactive treatment: none
- SFX posture: sparse (optional soft tick on node reveals / a gentle chime on celebrate)
- Restraint rule: audio must never overpower; no big risers or stingers.

## Storyboard
